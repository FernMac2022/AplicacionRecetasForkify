# Prueba rápida

1. Ejecuta `npm install`.
2. Ejecuta `npm start`.
3. Al abrir la aplicación deben aparecer recetas de pizza inmediatamente.
4. Prueba búsquedas como `pizza`, `pasta`, `chicken`, `avocado` o `tomato`.
5. Haz clic en una receta y verifica que el detalle aparezca en el panel derecho.
6. Si la API remota no está disponible, la aplicación conserva ejemplos locales para demostrar el funcionamiento de MVC, eventos y renderizado.
