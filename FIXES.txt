FORKIFY - CORRECCION FUNCIONAL

Problemas corregidos:

1. Se eliminó el import de la librería antigua "fractional" desde recipeView.js.
   La versión incluida es muy antigua y puede provocar errores de ejecución en
   entornos JavaScript modernos. La conversión de cantidades ahora se realiza
   localmente (0.5 -> ½, 0.25 -> ¼, etc.).

2. Se actualizó el endpoint a la API actual de Forkify:
   https://forkify-api.jonas.io/api/v2/recipes

3. La aplicación muestra recetas de ejemplo INMEDIATAMENTE al abrirse.
   Esto permite verificar que vistas, eventos, MVC y renderizado funcionan aun
   cuando la API remota esté lenta, bloqueada o sin conexión.

4. En segundo plano la aplicación intenta actualizar la lista usando la API
   real de Forkify. Si funciona, se muestran los resultados remotos. Si falla,
   se conservan los resultados locales.

5. Las búsquedas manuales también intentan primero la API y usan los ejemplos
   locales como respaldo cuando no hay conexión.

6. Se aumentó el timeout de la API a 8 segundos y se mejoró el manejo de errores.

EJECUCION LIMPIA

1. Descomprime este ZIP en una carpeta NUEVA.
2. NO copies node_modules de una versión anterior.
3. Abre la terminal dentro de la carpeta forkify.
4. Ejecuta:

   npm install
   npm start

5. Abre la URL que indique Parcel (normalmente http://localhost:1234).

AL ABRIR LA APP DEBEN APARECER RECETAS DE PIZZA INMEDIATAMENTE.
